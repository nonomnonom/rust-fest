# Rust Fest 0.1.0

Essential Rust utility types. `no_std` + `alloc`, optional Serde.

## Install

```sh
cargo add rust-fest
```

For serialization support:

```sh
cargo add rust-fest --features serde
```

## What this release adds

| API | Use case | Guarantee |
| --- | --- | --- |
| `Tagged<T, Tag>` | Keep user IDs, order IDs, and other domain values distinct | The compiler rejects mixing different tags; the wrapper has the same layout as `T` |
| `NonEmptyVec<T>` | Require a recipient, task, or batch item | Checked construction and restricted mutation preserve at least one element |
| `NonEmptyString` | Require text in configuration and API data | Checked construction preserves at least one UTF-8 byte |
| `Either<L, R>` | Accept one of two valid input forms | Exhaustive pattern matching, borrowing, and mapping preserve the selected alternative |
| `EmptyError` | Propagate failed non-empty validation | Integrates with standard error handling |

The `serde` feature serializes tagged values as their inner value, non-empty
collections as sequences, and non-empty text as strings. Deserialization routes
through checked constructors, including inside nested payloads. `Either` uses
explicit `Left` and `Right` variant names.

## Compatibility

- Stable Rust 1.85 or newer; edition 2024.
- `no_std` with `alloc`; an allocator is needed for the owned collection types.
- No runtime dependencies by default. Serde and its derive support are optional.
- No unsafe code in this crate.
- MIT OR CC0-1.0, at the user's choice.
- This initial `0.1` API has no earlier public release to migrate from. Breaking
  changes will require a new minor version during `0.x` development.

## Validation

- Public API integration tests cover constructors, mutation, iteration, hashing,
  borrowing, panic recovery, layout, and generic trait bounds.
- Compile-fail documentation tests reject mismatched tags, weakened tag
  lifetimes, invalid thread transfers, and attempts to empty non-empty values.
- Serde tests cover round trips and rejection of empty or invalid nested input.
- Stable and Rust 1.85 tests, formatting, Clippy, rustdoc, and package verification.
- CI tests Linux, macOS, and Windows and checks the `thumbv7em-none-eabi` target
  with and without Serde to verify the library does not depend on `std`.

## Try it

```sh
cargo run --example usage
cargo run --example api_payload --features serde
```

## Scope

Tags label values without validating their contents. Tags are not included in
serialized data and do not authenticate IDs. Non-empty strings may contain only
whitespace. These types do not perform authorization or domain-specific checks.

The collection focuses on reusable guarantees with a small public API. Use
Rust's `Option`, `Result`, or a domain-specific enum where those express your
problem directly.
