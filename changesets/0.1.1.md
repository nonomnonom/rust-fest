# Rust Fest 0.1.1

This release adds iterator interoperability, non-empty mapping, and JSON Schema support.

- `Either` can now unify different iterator implementations without allocation. Standard adapters, reverse iteration, exact lengths, and fused behavior follow the traits of both branches.
- Enable `either` to convert to and from `either::Either` with `.into()`, including in `itertools::partition_map` closures. Existing rust-fest types and serialized variants retain their identity and format.
- `NonEmptyVec::map` consumes and transforms a batch while preserving its length and non-empty guarantee, without another fallible constructor.
- Enable `schemars` for JSON Schema generation: non-empty arrays and strings carry minimum constraints; tags remain transparent; `Either` retains its externally tagged representation.

```sh
cargo add rust-fest@0.1.1
# Enable integrations as needed:
cargo add rust-fest@0.1.1 --features serde,either,schemars
```

The integrations are independently optional and support `no_std` + `alloc`.
The default dependency set is still empty, and the minimum Rust version remains 1.85.
New integration tests cover both iterator branches, conversion through itertools,
cardinality-preserving mapping, generic and recursive schemas, and tagged optional fields.
Existing constructor, mutation, Serde, and compile-fail tests remain in place.
